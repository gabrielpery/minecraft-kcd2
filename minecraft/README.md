# Fabric client bridge

Pinned tested build combination: Minecraft **1.21.1**, Fabric Loader **0.16.14**,
Fabric API **0.116.17+1.21.1**, Yarn **1.21.1+build.3**, Fabric Loom **1.10.5**,
Gradle **8.14.3**. Build runs on installed JDK 24 and emits Java 21 bytecode.
The wrapper verifies the Gradle distribution SHA-256. Dependencies and Gradle
caches can remain inside this project; no installer or global PATH change is needed.

The new opt-in [sampled-ground movement lab](../kcd2/MOVEMENT-LAB.md) passes real
client/server walking, jumping and landing against an approximate patch captured
from KCD2 terrain. Use `../scripts/Start-GroundMovementLab.ps1` with the official
test world already loaded. It creates a new empty Adventure save and closes after
its bounded test. It does not yet move KCD2's player/camera.

From the project root, `./scripts/Build-Minecraft.ps1` discovers an installed JDK
21 or 24 from `JAVA_HOME` or the environment inventory, runs the wrapper build
and then the independent codec tests. Pass `-JavaHome <path>` to select one explicitly.
It restores process environment variables and never launches a game.

From this directory in PowerShell, point `JAVA_HOME` at an installed JDK 24:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-24'
$env:GRADLE_USER_HOME = Join-Path $PWD '.gradle-user-home'
.\gradlew.bat --no-daemon build
```

Output: `build/libs/minecome-fabric-0.1.0.jar`. The source JAR is not a runtime mod.
The Gradle build includes the standalone codec and runs its test executable.

Launch an isolated development Minecraft instance:

```powershell
.\gradlew.bat --no-daemon runClient -PminecomeTokenFile="$((Resolve-Path '../config/bridge.token').Path)" -PminecomeExportStone
```

Loom uses this directory's `run/` for saves, options and logs. This does not modify
the launcher's normal `.minecraft` instance or its saves. Start a local single-player
world to send actual player/world/camera state. Never use the integration on a server.
The mod exports an empty-state pose at the title screen, with player/camera/world
flags unset. The CLI harness sends synthetic state and says so in its output.

The native host must already be listening on **127.0.0.1:38765**. The token is a
64-character hexadecimal secret generated by project setup. The default token path
is `config/bridge.token` inside the Minecraft instance; alternatively pass the absolute
path as `-Dminecome.tokenFile=...`. Tokens are read locally and never printed.

Implemented behavior:

- Authenticated Hello, versioned binary framing, 1-second heartbeats, a 6-second
  disconnect timeout and 1-second retry delay.
- Real client player coordinates, render camera position and camera-to-world quaternion
  sampled only on the client thread, then sent through an immutable mailbox at 20 Hz.
- Camera local axes are +X right, +Y up, -Z forward. The quaternion comes directly
  from `Camera.getRotation()`. Options FOV is sent in vertical radians; dynamic FOV
  changes during sprint/zoom/death still need a renderer accessor.
- Observation of real vanilla block changes in a radius of four blocks around the
  player, sampled at 10 Hz. Initial chunks/region entry establish a baseline and do
  not emit placement events. This is an observation feed, not a persistent block map.
- `/minecome status` shows diagnostics. `/minecome export-stone` exports actual
  vanilla `Blocks.STONE` BakedModel quads and its active block atlas to
  `minecome-export/stone/stone.obj`, `stone.mtl` and `block-atlas.png` inside the run
  directory. Opt-in `-PminecomeExportStone` performs this export once at the title
  or accessibility screen after resource loading. Assets remain user-local, outside source distribution.

No received host pose changes Minecraft movement, camera, collisions, saves or
inventory in this first build. The socket daemon calls no Minecraft API. Client
shutdown attempts Goodbye and closes the socket; host failure leaves vanilla playable.

## Repeatable real-game smoke test

```powershell
.\gradlew.bat --no-daemon runClient -PminecomeTokenFile="$((Resolve-Path '../config/bridge.token').Path)" -PminecomeExportStone -PminecomeSmokeWorld -PminecomeExitAfterSeconds=180
```

`minecomeSmokeWorld` is an explicit development opt-in. It creates a fresh flat
Creative/Peaceful world under `run/saves/MineCome-Lab-<UUID>`, checks that the save
does not exist, waits for authenticated bridge connection, gives stone through the
vanilla Creative inventory packet, places it through the vanilla interaction
packet, verifies the real client world contains stone, then breaks it through the
vanilla Creative attack packet and verifies air. It logs `VANILLA_SMOKE_PASS` or
`VANILLA_SMOKE_FAIL`, aims the lab camera at the block and uses Minecraft's actual
ScreenshotRecorder to save `run/screenshots/minecome-smoke-placement.png`. The
smoke test disables pause on lost focus and dismisses the pause menu in this
isolated lab profile, so vanilla can run while KCD has focus. It schedules normal
Minecraft shutdown 90 seconds after the lab world starts. Set
`-PminecomeSmokeWorldSeconds=300` for a longer live integration test (30..3600 s).
`minecomeExitAfterSeconds` provides a startup fallback. None of these test
actions run during ordinary play without the smoke property.

JDK 24 successfully built and ran the test on this machine. Minecraft's bundled
older LWJGL emitted an unsupported JNI version warning; use a Minecraft-supported
Java 21 runtime for ordinary installed-game play. Gradle 8.14.3 remains pinned
because it supports the installed build JDK 24.

Primary dependency sources: [Fabric Maven](https://maven.fabricmc.net/),
[Gradle Java compatibility](https://docs.gradle.org/current/userguide/compatibility.html).

authenticated session and a host pose<=1 second old with HAS_PLAYER|HAS_CAMERA.

publishes flags3. This gate does not claim the KCD stone sink is ready or acknowledged.
After6 seconds it places stone with vanilla interaction; both real client and
integrated server must confirm before a15-second wall-clock hold begins. It then
breaks through vanilla and verifies air. `-PminecomePort=...` selects the loopback
port; normal runs remain38765. See the project `scripts/Start-BlockMirrorTest.ps1`
for the combined test against an already-running official development world.

Observation baselines and queued events reset on client world/dimension identity
change, with fresh TCP authentication because wirev1 has no world ID. Every queued
event carries its connection generation, and overflow closes/resets the session
rather than silently losing a removal. Property-only changes with the same registry
ID do not emit remove/add. `/minecome status` reports queued/written/dropped events,
pending count and session/world generations. Socket-written counts are not engine
acknowledgements; only the native consumer's validated Lua receipts establish them.

## Opt-in interactive stone lab

`-PminecomeInteractiveStoneLab` starts a newly created UUID flat Creative save,
without automatic placement/breaking or a timed Minecraft exit. The native official
tools host uses `--interactive-stone`, optional wire minor1/capability1. After the
`INTERACTIVE_STONE_LAB_READY` marker, KCD console commands `minecome_place` and
`minecome_break` request real vanilla actions on one fixed supported cell near spawn.
Use `scripts/Start-InteractiveStoneLab.ps1` for the combined setup.

check connection/world/reset generations, one-second age, fresh host state,
ownership of the new lab, Creative mode, loaded chunks, reach, solid support and
expected air/stone state. Vanilla APIs perform the action; no direct block-state
mutation is used. Result1 is dispatch accepted. `STONE_INPUT_VANILLA_CONFIRMED`
requires separate actual client and integrated-server state observation. Normal
client shutdown saves the lab; native disconnect/stop clears transient KCD entities.
KCD movement/camera and Minecraft player physics remain independent.

The updated Java build passes3,428 protocol/socket checks,25 smoke timing checks
and17 action-gate checks. These verify the new control code in standalone tests;
live KCD commands now have matching real client/server and engine receipts after
the relay's unterminated-log-tail fix. The default minor0 smoke behavior
is retained.

and needs no physical input. Complete [the source setup](../docs/SETUP.md) first,

